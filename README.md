# Pomodoro Music Player

Учебный веб-проект: Pomodoro-таймер с музыкальным плеером на обычных HTML, CSS и JavaScript.

## Что уже есть

- Настройка времени фокуса, короткого перерыва, длинного перерыва и количества фокус-сессий.
- Одна главная кнопка `Play` для запуска Pomodoro.
- Автоматическое включение музыки во время фокуса.
- Верхняя панель плеера: выключение музыки, громкость, следующий и предыдущий трек.
- Встроенные плейлисты с синтезированным фоновым звуком.
- Свой плейлист через загрузку аудиофайлов, выбор папки или drag-and-drop.
- Прогресс текущего этапа.

## Как открыть

Открой `index.html` в браузере или запусти локальный сервер из папки проекта:

```bash
node dev-server.js
```

После запуска открой:

```text
http://localhost:4173
```
